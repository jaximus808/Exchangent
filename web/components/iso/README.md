# Exchange figure

Projection and solid geometry are vendored from [Anatomy](https://github.com/wheresryan22/anatomy), MIT © 2026 Ryan; see `ANATOMY-LICENSE`. No dependency, WebGL, remote code, or remote asset is loaded at runtime.

The compact Figure uses a buyer desk, three seller counters per page, offer-card trays, terminals, feet, shelves and fixings. The planar links are semantic message routes, not simulated physical pipes. Native HTML seller buttons filter the same saved transcript as the table. Pagination handles any seller count. Prices are read from the conversation; the saved reservation determines the selected seller.

Packets run once on a newly observed recorded message after initial load. Initial history is not animated as live traffic. No packets while disconnected, offscreen, or under reduced motion. The map does not simulate negotiations, create offers, or prove runner health. All operations remain available via structured MCP tools; graphics are optional read-only UI.

Price trends show **recorded seller offers only**, ordered by timestamp, using ordinal offer sequence on x and actual price on y. Buyer counters are excluded. Expired prices remain history; actionable eligibility still comes from the current offer and expiration.
